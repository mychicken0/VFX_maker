# Third-party notices

VFX Maker 0.7.4 uses pinned npm packages. The browser build includes PixiJS, PixiJS Filters, React, React Flow, Three.js,
Zod, gifenc, fflate, UPNG.js, pako and their dependencies. Node tools use the official MCP SDK,
Commander, Playwright Core and esbuild.

The exact installed runtime inventory, package integrity values and upstream
repository URLs are in [npm-runtime.json](docs/licenses/npm-runtime.json).
Upstream license/notice texts are collected in [npm-runtime.txt](docs/licenses/npm-runtime.txt).
Runtime inventory: 145 installed packages, including the browser libraries.
Platform-specific optional packages may differ on another operating system.

Demonstration textures are original project assets. Application code is original;
upstream packages are included with their notices.
