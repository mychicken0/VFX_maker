# Rendered examples

These frozen examples are produced by the actual tool and retained with source,
so they remain available independently of a cloud workspace.

Version0.3 examples:

- [Charge and impact](charge-impact.gif): delayed independent emitters, imported
  flipbook data, textured debris and layers.64×64 native,3× GIF scale,25FPS.
- [Portal loop](portal-loop.gif): periodic particle ages, sprites, wave distortion
  and alpha mask.64×64 native,3× GIF scale,25FPS,2second cycle.

Historical0.2 examples:

- [Red magic sword cross](red-magic-cross.gif):96×96 native,5× GIF scale,25FPS,
  30frames,seed42,opaque background#100811.
- [Original12 effects](overview.gif): presentation montage of actual exported GIFs.

The GIFs use an opaque matte; PNG atlases preserve partial transparency. Recreate
scenes from their data recipes through the installed CLI. See the [example guide](../README.md)
and [production workflow](../../docs/PRODUCTION_WORKFLOW.md). The montage is a
preview composition, not an engine export format.
