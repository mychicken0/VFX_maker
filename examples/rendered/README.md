# Rendered examples

These are frozen visual examples produced by VFX Maker 0.2.0, included so they
remain available from the repository independently of the cloud workspace.

- [Red magic sword cross](red-magic-cross.gif): native 96×96 project, 5× GIF scale,
  25 FPS, 30 frames, seed 42, opaque background #100811.
- [All 12 effects](overview.gif): presentation montage of the actual exported
  GIFs, each repeating at its original timing. Individual PNG atlases retain
  transparency; these GIF previews use an opaque matte.

Recreate the sword with the commands in [the example guide](../README.md).
Render the complete editable gallery with `scripts/render_gallery.py` from the
repository root. The montage is a preview, not an engine export format.
